# SmartSubtitles

Enjoy films and series in their original language, with help only when you need it.

For advanced English speakers, smart subtitles clarify difficult speech, accents, slang, names and cultural references without captioning every easy line. For other language learners who enjoy original English content, learner editions replace a few useful expressions with a target language while keeping the surrounding English, music and performances.

- [Movies](workflows/MOVIES.md): selective English subtitles, brief definitions and an illustrated guide.
- [Series](workflows/SERIES.md): the same, with shared terminology, episode summaries and season memory.
- [Language learners](workflows/LANGUAGE_LEARNER.md): English → a chosen target language, with voice cloning and bilingual learning cards.

An agent reviews the full transcript and audio evidence and makes the editorial choices. Local tools handle transcription and media processing; this is an agent workflow, not a one-click application.

Start with [setup](workflows/SETUP.md) and give your agent [these instructions](AGENTS.md). No movies, voice samples or model weights are included.
