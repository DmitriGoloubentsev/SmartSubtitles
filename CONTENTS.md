# Distribution contents and provenance

This folder contains workflow documentation, locally authored media-processing utility code and synthetic examples. It contains no films, episodes, commercial subtitle tracks, extracted dialogue, screenshots, plot recaps, character dossiers, actor reference audio, generated cloned voices, model weights or vendored third-party software.

The examples are invented to illustrate file structure; they are not excerpts from a show. Dependency names, links, version numbers and model identifiers identify external tools. Download those separately under their respective terms. No license to external media, model weights or third-party software is conveyed by this repository.

The workflow methods were developed using local media experiments. Those private assets and episode-specific scripts are intentionally not part of this upload folder. Smart-subtitle extraction/ASR/delivery utilities are included; the learner workflow specifies the method and synthesis commands but requires per-source implementation of separation, alignment, mixing and packaging.

Before uploading, check `git status`/the file list for local media, generated outputs, secrets, cache folders or voice references. The `.gitignore` excludes typical work products, but inspect the actual staged files as well. A project license has not been chosen here; the repository owner should choose licensing for their own documents/code before representing it as licensed open-source software.
